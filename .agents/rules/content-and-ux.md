# Content and UX Rule

- Never invent the owner's name, biography, employers, dates, education, skills, project details, metrics, awards, testimonials, or contact information.
- Use explicit placeholders until the owner supplies verified content.
- Featured conversations are read-only templates. Fork/copy a template before a visitor continues it.
- The portfolio assistant must distinguish verified portfolio facts from general AI knowledge.
- Keep portfolio Q&A useful when no LLM provider is configured.
- Provide clear empty, loading, error, offline, and no-provider states.
- Ensure keyboard access, visible focus, responsive layouts, and reduced-motion support.
