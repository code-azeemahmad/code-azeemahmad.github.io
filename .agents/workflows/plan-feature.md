# Workflow: Plan a Feature

1. Inspect the repository and current implementation.
2. Read `AGENTS.md` and the relevant product, architecture, design, and security docs.
3. Identify user-visible behavior and acceptance criteria.
4. Identify affected Astro pages, React components, data, retrieval, provider, and storage modules.
5. Check static-hosting compatibility and privacy/security implications.
6. Break work into small tasks in `project-management/tasks.md`.
7. Present assumptions and unresolved decisions before implementing anything that changes scope or architecture.
