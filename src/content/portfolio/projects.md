# Projects

## Conversational AI Portfolio
- Summary: A ChatGPT-inspired interactive portfolio featuring client-side retrieval and optional BYOK live LLM capabilities.
- Problem: Traditional portfolios are static and passive, making it tedious for recruiters and clients to find specific information quickly.
- My Role: Lead Architect and Developer.
- Solution: Built a static-first web app with Astro, React islands, and a browser-side retrieval pipeline that allows conversational exploration of skills, background, and projects.
- Technologies: Astro, React, TypeScript, Tailwind CSS, Client-side RAG.
- Outcomes: Sub-second initial load, 100% static output for GitHub Pages, zero-backend cost, interactive without requiring an API key.
- Repository: https://github.com/code-azeemahmad/code-azeemahmad.github.io
- Live Demo: https://azeemahmad.me
