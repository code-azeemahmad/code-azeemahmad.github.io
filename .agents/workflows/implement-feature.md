# Workflow: Implement a Feature

1. Confirm the task and acceptance criteria.
2. Inspect existing code; do not overwrite working features blindly.
3. Implement the smallest coherent change using existing patterns.
4. Add/update types, validation, tests, and accessible states as appropriate.
5. Verify there are no server-only dependencies or secret values in the client bundle.
6. Run available checks and the production static build.
7. Update relevant docs, `project-management/tasks.md`, and `project-management/progress.md`.
8. Report files changed, checks run, results, and any remaining limitations.
